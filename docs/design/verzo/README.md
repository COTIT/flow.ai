# Verzo brand assets

The Connected Workflows symbol pairs with a Structured wordmark. The capitals have lightly softened corners, and the angled O echoes the interlocking symbol.

- Use `lockup-light.svg` on warm white or similarly light surfaces. Use `lockup-dark.svg` on charcoal, navy, and dark photography.
- Use the full lockup in navigation and communications. Use the wordmark where the symbol is already present. Use the standalone symbol for browser tabs and compact controls.
- Set the full lockup at 100 px wide or more. Keep at least one quarter of the symbol's drawn height clear around the visible artwork. At 16 px, use `favicon.svg`.
- Use the mono SVGs where artwork must print or render in one color. Set `color` on the SVG when embedding it inline. Export as black or white for print and file handoff.
- Office uses gold on charcoal for its app tile. Till uses navy on gold. Use the maskable PNG where the operating system applies an icon shape.
- Source vectors are under `assets/`. The download also includes Office and Till install icons in `pwa/` and English, Dutch, and Swahili social cards in `social/`. In the apps, the PWA PNGs live in the Office and Till public icon sets, and the landing app renders the 1200 × 630 social cards using the dark lockup.
